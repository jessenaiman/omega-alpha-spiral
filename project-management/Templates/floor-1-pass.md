# Floor 1 — Echo Descent, first floor pass (revised per owner ruling 2026-09-20)

## Model (owner clarification, 2026-09-20)

- **Each stage has 3 floors.** Stage 2 = our three Dreamweaver floors (Light, Shadow, Ambition).
- **Each floor has one Dreamweaver who built it** — the floor's `owner`.
- **Each floor has 3 exit locations:**
  1. **Exit door** — the real way onward
  2. **Fight** — a monster guarding the floor
  3. **Secret** — stash/hiding (chest; random clue flashes, etc.)
- **Each exit choice is a Dreamweaver affinity option.** Choosing it triggers *that* Dreamweaver
  (the one aligned to the exit, not necessarily the floor builder) to say something.

## Idea

Make the first playable floor of the Echo Descent feel like the story the owner asked to play
(stage_2/nethack-scene.md): three Dreamweaver voices overlap as you arrive, Omega's system line
punctuates it, and each object you approach is interpreted *by the aligned Dreamweaver*, not just
read as static flavor text. The layout breathes between runs without ever hiding the decision.
