 The credential probe (threejs-game-director/scripts/probe_asset_credentials.sh) sources the user's shell profile (.zprofile/.zshrc/.bash_profile/.bashrc) in a child shell. The environment doc says the agent process usually does not inherit that profile, which is exactly why the probe reported all three MISSING. The script has no Windows fallback and no guidance for "probe says MISSING but the user believes a key is configured."
