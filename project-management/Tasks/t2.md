## Acceptance

- The opening loop plays in order through **real input**, not as a cutscene: black → bare blinking cursor → code begins moving → the first question ghostwrites (with mistakes) → the UI pulls off the frame and becomes a flat-but-3D object → a Dreamweaver types a message.
- The Dreamweavers follow the **primitive ladder** — dot → line → box → icon → onward — and **never regress**. Each rung appears only once the Omega code loop has added it.
- The environment reads as *progressively loading more advanced assets* throughout the scene.
- All three Dreamweaver visual identities are present and distinguishable by **shape and motion, not colour alone**.
- **No face is ever shown.** (Any face later is an upgrade, not a reveal.)
- Omega asks the **first and last** questions; each Dreamweaver asks its own.
- The scene ends on: the player is asked about their name → the player enters their name → Omega replies cryptically → **cut and transition**. Omega's message ends there.

## Open contradictions to settle (not silently resolved)

1. **Question count.** The 2026-09-17 clarification said "each dreamweaver to pose 3 questions each"; the opening loop says "until each dreamweaver asks one question, and Omega gets the first and last ones." Best reading: one question each in Scene 1's opening pass, building to three each across later loops. Needs the user's ruling.
2. **The player naming Omega.** An earlier invariant read "the name the player gave Omega" as permanent across loops. The ending above has the *player* named and Omega's own name left as the mystery — Omega is never named in Scene 1. Superseding note recorded rather than assumed.
3. **Camera contract.** The design spec fixes the terminal camera to a "fixed front plane"; step 3 says the camera *pans out*. Either the contract changes for Scene 1 or the pan is a scale move on flat content.
4. **Shadow's randomness.** `docs/game/core-loop-contract.md` requires one fixed update order with seeded randomness so the deterministic test hooks stay reproducible. Shadow's "randomness in its direction" must run through the seeded RNG.
