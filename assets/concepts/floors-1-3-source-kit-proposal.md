# Floors 1–3 source-kit study

Status: **proposal for owner review**, generated 2026-09-24. This is concept art, not a playable capture, final model, or approved asset.

Purpose: compare one reusable rail/block family through Light’s straight Atari-like route, Shadow’s fractured diagonal late-Atari/arcade route, and Ambition’s stepped-curved early-NES route at one camera and scale. The module must change navigation before Floor 7 can quote it.

Prompt:

> Create one wide, three-panel production concept board for reusable Omega Spiral Floors 1–3 source geometry. Use the first reference as the approved sparse Atari-in-3D palette and scale: deep navy ground, crisp cyan/blue flat rails, one orange slit pillar, tiny block hero, wide empty playable space. Use the second reference ONLY for its straight / erratic-diagonal / stepped-curved route grammar, NOT its stone ruins, foliage, lighting, or level of detail. Each panel is same elevated 2.5D game camera and same object scale, with one clear compact traversable route snippet plus one large isolated source module on a neutral dark plinth; no text labels. Left Light Floor 1: a single perfectly straight cyan extruded rail with an orange slit pillar, four-color flat primitive Atari style, maximum negative space. Center Shadow Floor 2: exactly that rail cross-section broken into two or three hard segments and rotated on one erratic diagonal, one tiny orange raster seam, late Atari/arcade step, still mostly empty. Right Ambition Floor 3: the same modular block repeated as a square-stepped 90-degree curve around a small central target with a limited violet tile stamp, early NES density, still visibly made of primitive code blocks. In every panel the object visibly changes where the tiny hero can walk, with a clear path and three small exit approaches in the far field. Historical graphics progress one step at a time; avoid fantasy stone, plants, glossy metal, photoreal detail, high-poly sculpture, bloom, cinematic fog, decorative clutter, written text, logos, HUD, captions, and too many colors. Sharp silhouettes and game-ready modular construction.

Review: Light/Shadow share a recognizable rail section, while Ambition repeats that family around a target. The Ambition module still appears rounded in places; its final mesh needs an explicit square step rhythm. The tiny exit approaches are too abstract to validate Door/Monster/Chest readability. Next review must use a running frame at the same camera.

Usage: design reference only. It has not been converted to Blender geometry, texture, or game runtime asset.
