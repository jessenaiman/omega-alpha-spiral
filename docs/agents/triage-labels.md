# Triage Labels

Use these canonical labels on GitHub Issues in `jessenaiman/omega-alpha-spiral`.

| Canonical role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer must evaluate the issue |
| `needs-info` | `needs-info` | More information or a decision is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and unblocked for agent execution |
| `ready-for-human` | `ready-for-human` | Human action is required |
| `wontfix` | `wontfix` | Evaluated and intentionally not actioned |

Apply one state label at a time. Close completed issues after acceptance and verification evidence is posted; completion does not require a separate `done` label.
