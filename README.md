# omega-alpha-spiral

## Run the main game

```powershell
npm install
npm run dev
```

Open `http://127.0.0.1:5188/intro.html`.

For agent diagnostics, open `http://127.0.0.1:5188/intro.html?debug`.

## Verify a change

```powershell
npm test
npm run test:bot
npm run verify:visual
```

Agent work starts with `AGENTS.md`, `project-management/STATUS.md`, and
`project-management/BOARD.md`.
