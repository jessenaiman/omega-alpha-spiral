# Omega Spiral level design scorecard

Status: design review, 2026-09-24. The broad era arc and shape grammar are approved; the per-floor rendering vocabulary and town inheritance are proposals awaiting owner review. Scores here are not runtime quality measurements.

## Era construction gate

The [code-era construction reference](omega-code-era-design.md) now proposes a capability and an inherited layer for each Opening passage and Floor 1–8. It specifies era as a configurable shader/rendering component that can be layered per target. ✅ The attached eight-era artifact was reviewed as display-method and production-prompt data; its array order and several device-wide claims cannot be treated as strict chronology. 🔍 The proposed mapping and component controls are not owner-approved or implemented end to end, and have not been compared with a representative running frame for each stage. ❌ No stage passes the full visual gate until its source piece, in-game reuse, legible player/choice state, and live frame match the reference. Floor 7 also needs recognizable provenance for every recycled object.

## Dialogue studio UI check

✅ The live studio at `http://127.0.0.1:5212/omega-dialogue-studio.html` shows a readable Three.js text preview and a scene/era selector. 🔍 At the observed narrow desktop window, the scene-file/save controls wrap over the scene typography row; the screen exposes lettering controls but not the construction-layer rules that would guide geometry, material, motion, and sound. The visible `scene1.oml` selection displayed IBM PC VGA while that file declares `dec-vt100-ascii-terminal`, so the selected file and preview did not present one clear authored scene state. This is a studio UI and file-loading gap, not evidence that the game needs a studio connection. A follow-up studio pass should make the active file, its scene method, and the preview agree, then place the era design card next to the preview without covering it.

✅ [GhostLetters](../../src/intro/ghost-type-study/GhostLetters.ts) already renders lettering with a `ShaderMaterial` and scan/dot/halo/cell uniforms. ❌ The proposed era treatment is not yet a configurable component that can be attached and blended per prop, path, surface, and letter group. The studio's global text-era selector must not be scored as that wider component.

Until then, mixed pixel densities or aspect ratios are an experiment, not a finished multi-era town.

## Runtime visual scoring

The director's [ten-category rubric](../../.agents/skills/threejs-aaa-graphics-builder/references/visual-scorecard.md) applies to active play. This concept scorecard does not invent per-category runtime scores. The isolated current-view inspector measured color entropy 0.22 bits, edge density 0.027, and dominant-color share 0.977; it saw no browser console or page errors. These measurements describe the old sparse glyph baseline, not the approved Stage 1 scene.
